# Git Basics — Learning Project

## Purpose
Teach Git from scratch, one topic at a time, for an absolute beginner.
Mentor verifies student results before moving to the next topic.

## File Convention
Every topic folder must have two lesson files:
- `README.en.md` — English
- `README.ro.md` — Romanian (limba română)

## Active Plugins
- `explanatory-output-style` — use clear, educational explanations throughout
- `superpowers` — use `writing-plans` before creating each new topic, use `verification-before-completion` before marking a topic as done

## Teaching Style
- One topic at a time
- Real-life analogy first, then the concept
- Show exact commands and what they do
- End each topic with short practice tasks (under 5 min each)
- Student completes tasks, mentor verifies with `verification-before-completion`, then advances
