# Tema 01 — Ce este Git?

## Analogia

Imaginează-ți că scrii un eseu la școală și salvezi copii astfel:
- eseu.docx
- eseu_v2.docx
- eseu_FINAL.docx
- eseu_FINAL_chiar.docx

Devine haos rapid. Git rezolvă exact această problemă.

## Ce este Git?

Git este un **sistem de control al versiunilor**. El urmărește fiecare modificare pe care o faci în fișierele tale.
Gândește-te la el ca la o mașină a timpului pentru proiectul tău.

- Poți salva un "instantaneu" al proiectului tău în orice moment.
- Poți reveni la orice instantaneu anterior.
- Poți lucra la mai multe versiuni în același timp (ramuri/branches).
- Mai multe persoane pot lucra la același proiect fără să se suprascrie.

## Termeni Cheie (pe înțelesul tuturor)

| Termen       | Înțeles                                                        |
|--------------|----------------------------------------------------------------|
| Repository   | Un folder pe care Git îl urmărește (numit și "repo")           |
| Commit       | Un instantaneu salvat al proiectului tău                       |
| Branch       | O linie separată de lucru în același repo                      |
| Merge        | Combinarea a două ramuri                                       |
| Remote       | O copie a repo-ului tău stocată online (ex. GitHub)            |

## Git vs GitHub

- **Git** = unealta instalată pe calculatorul tău
- **GitHub** = un site web care stochează repo-urile tale Git online

Git funcționează complet offline. GitHub este opțional (dar foarte util).
